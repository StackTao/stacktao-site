# 简历页与 PDF

## 使用

- 页面：`/#/resume`；后台：`/admin/#resume`。
- 后台填写姓名、目标岗位、简介、联系方式以及各栏目下的经历。成果每行一条，支持增加和移除栏目、条目。
- 点击「保存并构建」后，网页与 PDF 由同一份内容更新。空姓名不允许保存。
- 示例内容由用户授权用于设计预览；默认 `draft: true`，网页和 PDF 都有「示例」标记。换成真实信息后，将内容状态切换成正式简历。
- 点击「导出 PDF」调用浏览器打印。选择「另存为 PDF」、A4、100% 缩放，关闭浏览器页眉页脚。正文是文字，不是截图，链接可点击。
- 桌面保持 A4 内容宽度；手机改为单栏阅读，但打印时仍恢复相同 A4 排版。较长内容自动分页，不通过裁切或缩小全文塞进一页。

## 数据与接口

简历保存在现有持久化 `content.config.json` 的 `resume` 字段，随内容目录备份。没有配置姓名时不生成简历路由，也不添加页脚入口；不会凭空发布默认个人资料。

后台复用 `GET/PUT /api/v1/settings`，需要现有登录或具有 `settings:write` 权限的令牌。先 GET 取得完整配置及 revision，在保留其他字段的前提下修改 `resume`，再 PUT 完整配置并带 `If-Match: <revision>`。并发修改返回 409，避免覆盖他人的设置。

```json
{
  "draft": true,
  "name": "苏",
  "role": "目标岗位",
  "monogram": "SU",
  "updated": "2026.10",
  "summary": "个人简介",
  "contacts": [{ "label": "邮箱", "url": "mailto:hello@example.com" }],
  "sections": [{
    "title": "工作经历",
    "caption": "EXPERIENCE",
    "items": [{
      "title": "公司 · 职位",
      "period": "2023 — 至今",
      "subtitle": "职责范围",
      "url": "",
      "points": ["完成了什么，产生了什么结果。"]
    }]
  }],
  "footer": "保持好奇，把事情做好。"
}
```

字段按纯文本输出，链接仅允许 HTTP(S) 与 mailto。正文使用本地 Noto Sans SC 分包字体（OFL），标题沿用本地霞鹜文楷；打印前等待字体就绪。没有把简历发送给第三方 PDF 服务。

## 验证

- `npm run test:resume`：HTML 转义、危险链接、示例标识、字体等待、离开页面取消打印、编辑保存、修改版本保护、保留其他站点设置。
- `npm run test:site`：原有站点、相册、文章和留言墙回归。
- 浏览器实际验证：390px 手机无横向溢出；后台新增、保存、刷新、删除经历；桌面/手机生成 A4 PDF 的文字坐标比较；14 段经历的多页导出与逐页文字检查。
