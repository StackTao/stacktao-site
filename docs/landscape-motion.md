# 山体与流雾动效

本次调整将背景从碎线草稿改为连续山脊与分层淡墨。远中景减少重复峰谷、抬高山谷连接，近景保留肩部与皴擦；正文安全区沿用既有遮罩。

- 山体在 5.2 秒内完成绘制。山脊笔段持续 1.1–1.65 秒，沿峰顶向两侧展开。
- 入场结束后缓存山体，流雾继续缓慢穿行，不重复计算山体几何或笔触。
- 桌面三条雾带、手机两条，横向周期约 45–69 秒，叠加小幅纵向移动。第 1.4 秒起渐显，第 4.4 秒达到稳定强度。
- 普通流雾最多以 30fps 合成；笔触生长与飞鸟活动按屏幕帧率绘制。
- 页面隐藏时取消动画帧与飞鸟计时器，恢复时补偿隐藏时长，避免相位跳变。
- `prefers-reduced-motion: reduce` 下不播放流雾、飞鸟或入场，直接显示静态山体。
- Canvas 的 `data-ink-motion` 标记 `flowing` / `still`，方便核验模式。

本次用户要求持续动态，因此取代原先“5.2 秒后整个背景永久静止”的限制。山体自身仍保持稳重，不做整体缩放或透明度呼吸。

验证：构建与 JavaScript 语法检查；1280×800 深浅色、390×844 手机布局；入场结束后山体区域像素变化及减少动态效果静态模式检查。
