# 水墨山水背景

背景采用 Canvas 程序绘制，不需要远程图片或额外运行时。2026-09-23 根据文章页反馈重做山形与墨法：旧版浅色平行波浪缺少山石体积与水墨识别度。

## 构图与墨法

- 桌面五层：连接两岸的淡远山、两组中景峭壁、左右近景山石。手机收为三层。采用受控的不对称峰谷轮廓与种子噪声，不堆叠相同波形。
- 岩面从山脊顺势垂落，分别叠加湿墨面、成组长短皴纹、积墨纸粒和山缘苔点。近景墨重，远景淡；山脚逐渐散入留白。
- 近景山肩点缀小松树，树干、侧枝与针叶作为墨笔参与入场。中央沿用正文安全区，江面以短而疏的水纹表达。
- 明暗主题复用同一几何与纹理种子，深色降低墨层亮度，避免发光山峰。

## 动画与性能

- 山体绘制在 5.2 秒内完成。湿墨由峰顶向下推进，使用柔边蒙版表现晕染；皴笔、树枝随后逐笔显现。
- 每座山的皴纹与纸粒只生成一次局部纹理。主题变化才更新颜色缓存，尺寸变化重建几何；每帧不重复计算纹理。
- 入场时使用的局部湿墨蒙版在完成后释放。最终山体合入静态缓存，持续动画只合成行雾、水纹与活动飞鸟。
- 桌面三条雾带、手机两条，周期错开约 45–69 秒；水纹横向轻移并缓慢变化浓淡，不整体摇晃山体。
- 普通环境动画最多 30fps；笔触生长和飞鸟活动按屏幕帧率绘制。后台暂停并补偿隐藏时长。
- `prefers-reduced-motion: reduce` 下直接显示完整山体与静态水纹，不播放入场、流雾或飞鸟。Canvas 的 `data-ink-motion` 为 `flowing` / `still`。

## 验证

- JavaScript 语法检查与完整构建。
- 截图所示 `/posts/tools-that-last` 文章页：1440×950 深浅色、390×844 手机布局，正文无横向溢出。
- 正常模式入场结束后对山体下部连续采样，确认雾与水纹变化；减少动态效果下全画布连续采样像素不变。
- 本机入场阶段抽样 1.5 秒，未观察到长帧；该结果不代表所有低端设备性能。
