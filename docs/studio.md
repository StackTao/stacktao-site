# StackTao / Personal Journal

2026-10-21：首页从作品展台改为个人博客。删除大口号、切换卡片和项目展示网格；保留内页的阅读版式。

## 设计主张

先认识作者，再读文章。首页以窄版作者介绍和近期文字为主体，项目作为写字之外的近况，照片成为另一种入口。互动只出现在文章的折页和给访客的纸条里，不自动播放、不遮挡正文。

参考 Rauno 的交互思路，不复制他的版式或作品：

- [Invisible Details of Interaction Design](https://rauno.me/craft/interaction-design)：即时反馈、操作可打断、空间关系清楚。
- [Designing Depth](https://rauno.me/craft/depth)：通过层次和遮挡说明交互，而非堆砌装饰。
- [Contrasting Aesthetics](https://rauno.me/craft/contrasting-aesthetics)：在整洁界面里留一点有意的反差与可以把玩的细节。

## 视觉系统

- 浅色：近白 `#fafaf9`、石墨 `#20211f`、灰绿辅助文字与表面。
- 深色：`#171816` 背景，`#f0f1eb` 标题，避免纸面反相。
- 中文标题与章节使用 Noto Serif SC / 宋体，英文题签与品牌使用 Instrument Serif，UI 与正文保留 Inter / 系统中文无衬线，日期使用 DM Mono；留言保留原始笔迹。字体加载失败时使用本地宋体、Georgia 和系统字体。
- 英文字体来源：[Instrument Serif / Google Fonts](https://fonts.google.com/specimen/Instrument+Serif)。
- 单个赭色强调用于品牌句点、焦点和阅读进度。首页不再使用抽象项目配图。
- 首页和正文容器800px（含左右各40px内边距）；项目、相册与留言墙保留宽版。手机内边距24px。
- 控件圆角7–11px，卡片12–16px，阴影只表达物件的距离。

## 页面与交互

1. 顶部导航：品牌、主要栏目、搜索、主题切换；RSS 在页脚。移动端导航可横向滚动，正文不会横向撑开。
2. 首页：作者姓名、简介、照片入口、近期六篇文章、少量项目文字链接。使用现有内容数据，原有完整介绍收在“再多认识我一点”中。
3. 折页：标题直接进入文章，右侧独立按钮展开真实第一段；一次只展开一篇。“随手翻翻”随机选择其他一篇，将结果移入视野并聚焦折页按钮。收起的内容不可获得焦点。
   页边纸条：小信封点击后展开给访客的话及留言入口，提示纸笺仅保存在当前浏览器。再次点击可折好；不在悬停时擅自打开。
4. 文字：归档先展示一段取自真实文章的文字，拖动页边书签抽取下一段，再进入数字年份目录。文章使用居中阅读轴、可折叠目录，宽屏目录靠右，顶部显示细阅读进度；文末连接下一篇文章和留言。
5. 项目：首个项目组改为项目目录与工作笔记，切换展示原说明和链接；有标题匹配的文章时呈现相关记录，不伪造产品截图。后续项目组保留。
6. 相册：主照片＋接触印样，支持上一张、下一张、主图和缩略图的方向键、Home/End、原比例与铺满、原有灯箱放大。无自动轮播。现有 Unsplash 示例素材标注来源；加载失败有文字反馈。
7. 演讲：按分享主题分段，场次记录可展开；没有分享记录的内容源保留原空状态。
8. 留言墙：整个视口是一面灰泥墙，隐藏该路由的导航、页脚、页标题与工具栏。点击空白位置才打开书写台，可选择刻字、墨迹或贴纸，手写/打字后在原点击位置留下痕迹。仍仅保存到当前浏览器。

## 页边书签

- 仅在文章与笔记归档的引文区出现，独占120px宽的交互区；正文、目录标题不跟随指针。
- 向下拖动带非线性阻力，横向拖动影响绳线与书签倾角；显示位移达到54px后松手，才随机抽取另一篇真实文章。
- 短拉、拖回阈值以内、Esc、指针取消均不翻页；释放后的原生click不会重复触发。
- 鼠标、触控、触控笔使用Pointer Capture，点击/Enter/Space提供原生按钮替代方式。
- 弹簧回弹可被重新抓住；运动稳定后停止requestAnimationFrame，路由切换、失焦和隐藏时清理。减少动态效果时直接回位。

## 首页相片与痕迹墙

- 首页照片入口改为可拨动的三张相片：左右拖过48px松手换张，短拖归位；相片拥有固定的独立展示区，标题、简介与文章列表不跟随移动。
- 点击相片、左右按钮及方向键都可换张；只让当前相片进入焦点顺序。触屏保留纵向滚动，纵向手势、Esc、取消及失焦不换张。
- 留言直接拖动整张纸笺：移动超过6px才拿起，拖动时浮起并有最多3度的轻微倾角，松开贴在新位置。点击仍打开详情，拖动释放不误开。
- 纸笺位置独立存储到 `stacktao-paper-wall-v1-positions-v1`，不改原留言结构。保存失败回退；取消、失焦、重排和切页放回原处。宽屏与窄屏分别存位置，横坐标按可用宽度归一化。
- 触屏默认滚动阅读；打开纸条详情后可选择“移动这张纸”，放下后恢复滚动。键盘空格拿起、方向键移动、Shift加快、空格或Enter贴好、Escape取消。刻痕与墨迹固定在墙面，不能拖动。
- 布局留有可摆放空白，纸张不能拖出墙面；重叠是允许的，后贴的在上面。新增纸张寻找空位，不重排已经保存的纸张。
- 已通过原型与生产构建的离线DOM测试：刷新恢复、原数据保持、点击与拖动区分、指针取消/丢失、键盘、触摸模式、越界限制、宽窄屏恢复、删除撤销、新增留言、配额失败与卸载。

## 动效

- 页面整体进入300ms，不再让长文逐段排队出现。
- 折页内容以400ms的网格行过渡原地展开；页角和信封仅局部运动。连续操作可改变过渡目标，没有等待锁。
- 项目切换460ms沿左边缘轻翻笔记，重复选择不播放，连续切换取消上一段动效；正文仅在切换时改变。
- 相册图片加载后520ms显影，缩略图悬停轻抬；分享记录340ms展开/收起，可连续反向操作。
- 播客条目的唱片在悬停或聚焦时转动一次，保持原有内容链接；支持者圆标轻抬，文章目录以细线反馈替代移动文字。
- 无常驻绘图循环或自动切换；新增的Web Animations在切页时取消，减少动态效果时直接显示结果。
- 纸笺打开280ms、张贴650ms，继承留言模块行为。
- `prefers-reduced-motion` 下移除过渡与入场，功能不变。

## 墙面化更新

留言墙常态只显示灰泥材质、墙上题字与用户留下的痕迹。没有导航、页标题、统计、工具条或卡片容器。材质使用代码生成的SVG噪点和渐变，未使用参考照片或新增外部图片。空墙的题字明确标注为非访客留言，访客计数不包含它。

三种媒介共享原始笔迹/文本存储：engraving表现凹痕，ink直接留在墙上，paper保留胶带或图钉。旧数据缺少medium时仍作为纸条。新记录的anchor记录落笔位置，原有positions存储继续兼容。提示只在操作时短暂出现。验证了三种媒介、空白处唤起、指定位置刷新恢复、刻痕不可拖、纸条可拖、拖动释放不误开编辑器、保存失败以及原留言回归。
