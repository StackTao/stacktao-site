# StackTao / Personal Studio

2026-10-21：重新设计整站。此前的山水、植物、四季背景和书脊布局不再是当前方向。

## 设计主张

一个可以浏览、阅读，也可以留下笔迹的个人工作室。重点是内容与可操作的物件：背景保持安静，动态发生在卡片切换、按钮反馈和纸笺张贴时。

参考 Rauno 的交互思路，不复制他的版式或作品：

- [Invisible Details of Interaction Design](https://rauno.me/craft/interaction-design)：即时反馈、操作可打断、空间关系清楚。
- [Designing Depth](https://rauno.me/craft/depth)：通过层次和遮挡说明交互，而非堆砌装饰。
- [Contrasting Aesthetics](https://rauno.me/craft/contrasting-aesthetics)：在整洁界面里留一点有意的反差。

## 视觉系统

- 浅色：近白 `#fafaf9`、石墨 `#20211f`、灰绿辅助文字与表面。
- 深色：`#171816` 背景，`#f0f1eb` 标题，避免纸面反相。
- 全站 UI、标题和正文采用 Inter / 系统中文无衬线；留言笔迹保留楷体及原始手写。
- 单个赭色强调用于品牌句点、焦点和阅读进度。项目视觉使用三组低饱和底色。
- 页面最大宽度 1120px；正文容器 800px（含左右各40px内边距）；手机内边距24px。
- 控件圆角7–11px，卡片12–16px，阴影只表达物件的距离。

## 页面与交互

1. 顶部导航：品牌、主要栏目、搜索、主题切换；RSS 在页脚。移动端导航可横向滚动，正文不会横向撑开。
2. 首页：大标题与可翻阅工作室卡片并置，下面依次为项目、近期文字、留言邀请。项目和文章取自现有页面数据；原有介绍收在“更多关于”中。
3. 卡片：三个入口“做东西 / 写下来 / 留句话”；点击或方向键、Home、End 切换。只有当前卡片可获得焦点，内容链接通往真实路由。不自动轮播。
4. 文字：数字年份、清晰的标题日期行；文章使用居中阅读轴、可折叠目录，宽屏目录靠右，顶部显示细阅读进度。
5. 项目、演讲、相册：统一字体、间距、边界与交互反馈，保留原有内容和功能。
6. 留言墙：浅灰绿墙面与真实纸张的反差。书写台采用分段工具条，支持手写、打字、预览、张贴、查看、收回和恢复。仍仅保存到当前浏览器。

## 动效

- 页面整体进入300ms，不再让长文逐段排队出现。
- 卡片切换600ms，CSS transition 可随下一次操作改变目标。
- 悬停反馈180–500ms；无常驻绘图循环或自动切换。
- 纸笺打开280ms、张贴650ms，继承留言模块行为。
- `prefers-reduced-motion` 下移除过渡与入场，功能不变。

## 实现与验收

- `css/studio.css` 统一新视觉层，覆盖旧内容模板的展示方式。
- `js/studio.js` 负责首页组合与卡片交互；`js/site.js` 保留路由、搜索、照片、主题和阅读状态。
- `js/guestbook.js` / `css/guestbook.css` 保留完整留言数据与交互，存储键没有改变。
- 原型与 `stacktao-site/public` 同步；生产构建包含新的样式和脚本。
- 已验证生产构建、JS/CSS解析、离线DOM中的卡片键盘操作、路由、目录与留言存储流程。
- 浏览器工具的安全策略阻止本地页面观察，因此尚未完成实际浏览器截图与尺寸复核；离线DOM测试不等于视觉验收。
