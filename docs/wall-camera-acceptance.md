# 留言墙缩放与跨端坐标验收

2026-10-23。视野相机只变换 DOM 场景，不写入留言记录。墙面基准仍为 1000 单位，`frame` / `worldBox` / `worldFontSize` / 笔宽保持原协议。

## 操作

- 双指捏合 1–4 倍缩放，以双指中点为锚；双指一起移动可平移。
- 工具启用时单指绘画；双指开始时撤回当前尚未结束的笔画/擦除/拖动，保留此前草稿。直到全部手指离开才允许再次落笔。
- 浏览时单指拖动；也可点十字拖动按钮。电脑可拖空白、用滚轮平移、Ctrl/⌘ + 滚轮缩放。
- `−` / `＋` 与比例还原按钮支持键盘。拖动按钮开启后，方向键平移视野。
- 工具栏和文字编辑面板不缩放；草稿把手抵消镜头倍率，保持可操作尺寸。
- 旋转时保留视野中心对应的墙面位置（在墙边会受边界限制）。先完成墙面布局，再限制相机范围，避免旧高度造成跳动。
- 墙册定位改为平移镜头，换墙还原视野。镜头不会修改作品，也不会让未修改的编辑变成脏草稿。
