# 留言墙缩放与跨端坐标验收

2026-10-23。视野相机只变换 DOM 场景，不写入留言记录。墙面基准仍为 1000 单位，`frame` / `worldBox` / `worldFontSize` / 笔宽保持原协议。

## 操作

- 双指捏合 1–4 倍缩放，以双指中点为锚；双指一起移动可平移。
- 工具启用时单指绘画；双指开始时撤回当前尚未结束的笔画/擦除/拖动，保留此前草稿。直到全部手指离开才允许再次落笔。
- 浏览时单指拖动；也可点十字拖动按钮。电脑可拖空白、用滚轮平移、Ctrl/⌘ + 滚轮缩放。
- `−` / `＋` 与比例还原按钮支持键盘。拖动按钮开启后，方向键平移视野。
- 工具栏和文字编辑面板不缩放；草稿把手抵消镜头倍率，保持可操作尺寸。
- 旋转时保留视野中心对应的墙面位置（在墙边会受边界限制）。先完成墙面布局，再限制相机范围，避免旧高度造成跳动。
- 墙册定位改为平移镜头，换墙还原视野。镜头不会修改作品，也不会让未修改的编辑变成脏草稿。

## 自动检查

`npm run test:site`、`npm run test:guestbook`、`npm run build`。

新增 `tests/wall-camera.cjs` 覆盖：中点缩放和剩余手指隔离；桌面与手机放大后的喷绘/刻画坐标、笔宽逐项比较；排队及已绘制的误触回滚；擦除、纸上手写时的双指切换；贴纸落点和拖动；草稿把手移动及碰撞；喷漆/刻字文本字号与边框；旋转焦点、1–4 倍边界；纯视野变化不污染编辑。

## 实际浏览器操作

独立测试站 `127.0.0.1:5176/site/#/guestbook`，独立 content/state 目录；未向线上写入测试作品。

- Chrome 390×844：通过浏览器的 `Input.dispatchTouchEvent` 输入真实双触点序列，从 100% 放至 250%；工具启用中再次双指缩放和平移，抬起一指后移动另一指，再全部抬起。保存后服务端仅有原先的 1 笔，没有误触点。
- 225% 下喷绘、手写刻画、整幅挪位置、刻字输入/预览/换位/保存、贴纸落点/保存/移动均实际操作。
- 贴纸预览与保存显示宽度均约 123.205 CSS px，服务端宽高仍为 148 墙面单位。移动 15×35 屏幕 px 后，服务端只更新位置，宽高未变。
- IAB 1280×720 同时收到手机保存的 4 处痕迹；电脑贴纸宽度约 182.336 CSS px，即 1232/1000×148。墙册定位到原视野外的作品正常。
- Chrome 844×390 横屏与竖屏切换：中心墙坐标从 (0.5, 0.9124324324) 到 (0.5, 0.9124324422)，误差为浏览器亚像素取整。
- 浏览器未见本站脚本错误；Chrome 翻译扩展有自身网络错误，与本站无关。

此验收使用桌面 Chromium 的触摸输入与手机视口模拟，不冒充 iPhone/Android 真机、Safari、软键盘或触控笔硬件验收。
