# 留言墙实时协作验收（2026-10-23）

## 行为

- `/api/wall/events` 仅推送公开的变更信号；客户端带自己的访客身份重新拉取快照。20 秒心跳，禁止代理缓冲，保留 2.5 秒轮询及重连补偿。
- 已保存留言独立更新；绘画笔画、输入框和光标不被共享快照替换。按下笔或拖动时延后到手势结束更新。
- 手绘和文字草稿分别保存在本浏览器，以窗口和墙号隔离。刷新原窗口可恢复；服务器仍在保存时检查占位、所有权和版本。草稿不是跨设备云同步，清除浏览器存储会删除草稿。
- 冲突不删除作品。自由笔迹支持整幅拖动，保留笔触、颜色和点集；拖动后重新申请占位。文字使用已有位置把手。
- 同一笔触用统一墙坐标宽度。文字按原排版宽度整体缩放，避免 flex 二次压缩或小字号重新断行。新创作字体选项采用本站已随包提供的文楷、马善政和 Caveat，旧系统字体记录以文楷兼容显示；字体加载失败时保留草稿并阻止按备用字体尺寸发布。

## 实际浏览器操作

使用隔离本机数据、IAB 与 Chrome 两个独立访客窗口：

1. A 喷涂；B 断网后在对应位置刻画；A 保存；B 恢复网络，看到 A 的已保存内容，自己的刻画仍在。
2. B 保存被服务器拒绝覆盖；整幅拖到空白处后保存成功，A 自动显示两份作品。
3. A 手绘后放回工具、刷新、恢复、保存，笔画保留。
4. B 输入刻字时 A 保存贴纸；B 的文字和光标位置保持，新增贴纸即时出现。
5. B 关闭文字编辑、刷新、恢复，原文本完整，成功保存。
6. Chrome 切到 390 × 844 手机模拟视口：修复文字容器 flex 收缩；手机和桌面各创建 24 号文字，两个记录的排版宽度均为 260 墙坐标单位。在桌面 1232 像素宽墙面上两者显示宽度均为 320.32 像素。模拟视口已恢复。
