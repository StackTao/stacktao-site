# 游墨：持续生长的自然笔触

2026-09-23：背景采用独立生长、停留和淡出的自然笔触，与纸色、宋体和阅读留白保持一致。参考 [antfu.me](https://antfu.me/) 的低干扰生成式背景，轨迹与生命周期独立实现，以主曲线、细支脉、局部断笔和淡墨点形成疏密层次，不使用成组平行线或流光轨道。

## 构图和运动

- 桌面九条线，手机四条。每条线独立随机选择入画方向、位置、长度、曲率、笔重与时间。
- 长主笔从画外进入，曲率平滑变化；笔尖在相邻采样点间插值，笔速有缓慢起伏。
- 每笔有 3–7 条疏密随机的细支脉，手机 2–3 条；支脉在主笔经过后依次生长。局部使用固定的断笔纹理，少量椭圆墨点随末梢淡入，不逐帧抖动。
- 每笔生长 9–14 秒、停留 1.8–3.5 秒、淡出 6.5–10 秒。淡出后在新的位置继续生成，生命周期错开，页面不整体重播。
- 普通模式一直运动；没有“全部画完后停止”的终态。
- 文章标题用同纸色柔边底保护，避免笔触穿过标题。桌面中部使用横向透明遮罩，761–1279px 进一步扩大正文安全区；手机使用纵向透明遮罩，降低整体透明度至 0.65。
- 刷新、路由和窗口尺寸变化重新构图；切换主题保留轨迹与时间进度。

## 性能与辅助功能

- 原生 Canvas，无外部依赖。最多 30fps 绘制九组笔触，不使用模糊滤镜、粒子或额外全屏缓存。
- DPR 上限 1.5，resize 防抖 180ms。后台暂停，回到前台延续时间。
- 减少动态效果下显示完整静态线稿并停止 rAF。
- `data-ambient-state`：flowing / still / paused；`data-ambient-generation` 记录线条再生次数，便于验证持续动画。

## 验证

检查浅深主题、文章和播客页、390px 手机视口。普通模式初始和运行 30 秒后像素仍变化，再生次数增加；减少动态效果下像素保持不变。检查控制台无脚本错误，并运行 `node --check public/js/site.js` 与 `npm run build`。
