# 墨色电流：随机折线与延迟分叉

2026-09-24：环境动画采用闪电式随机路径，使用低对比灰墨色与纸面排版配合。主线快速展开，细支线跟进，余迹缓慢淡去；不使用全屏闪光或发光滤镜。

## 构图和运动

- 桌面四组电流、手机两组，随机选择起点、终点、方向、粗细、分叉位置和时间。
- 主路径通过五轮随机中点偏移生成折线，支线使用四轮偏移。一次生成整条路径，播放时连续推进笔尖，不逐帧随机抖动。
- 主线在 550–950ms 内展开。桌面每组 4–7 条支线，手机 2–3 条；主线经过分叉点后延迟 60–160ms，支线再用 180–420ms 展开。
- 展开后停留 0.9–1.5 秒，再用 4.5–7 秒平滑淡去。各组独立重生，随机等待 0.3–1.1 秒后开始新路径，保持持续变化。
- 文章标题保留同纸色柔边保护；正文使用原有透明遮罩。手机降低透明度并保护画面中部；不超过 1023px 的文章页改为上下缘遮罩，避免电流穿过贴近边缘的正文。
- 刷新、路由和窗口尺寸变化重新构图；主题切换保留路径与时间。

## 性能与辅助功能

- 原生 Canvas，每秒最多绘制 30 帧，DPR 上限 1.5，resize 防抖 180ms。
- 后台暂停，返回后继续原进度；减少动态效果下展示静态完整线稿，不运行 rAF。
- `data-ambient-state`：flowing / still / paused；`data-ambient-generation` 记录再生次数。

## 验证

检查演讲页、文章页、浅深主题及手机视口；确认普通模式持续变化、再生计数增加、静态模式像素稳定。运行 `node --check public/js/site.js`、`npm run build` 并检查浏览器控制台。
