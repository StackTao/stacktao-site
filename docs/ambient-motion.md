# 疏梅：为正文留白的环境动效

2026-09-24：参考实物梅花的形态关系，重新设计灰墨木质树架与少量淡粉梅花。主干保留，不再让整棵树反复抽长、消失。

## 形态依据

梅花可单生或成对，花梗短，着生于前一年枝条的节点；选取单瓣品种的圆润五瓣与明显花蕊作为表现特征。这里是简化的装饰动画，不是植物生长模拟。

## 构图与节奏

- 桌面四株，前后景各两株；手机两株缩小到下缘。中央正文保留透明遮罩，标题沿用纸色保护。
- 主干采用连续曲线，分枝沿母枝切线柔和斜出，每株三条骨干枝，每条两处短花枝；六个花位疏落安排，部分节点伴有小花苞，避免成串排列。
- 树架用 2.4 秒渐显，骨干枝用 1.8–2.6 秒延展，短枝在父枝到达后用 1.6–2.6 秒展现，最后花苞用 7–9.5 秒开放，五瓣略微错时舒展，花蕊渐显。
- 花朵直径约 8–16px，五圆瓣与细蕊；低饱和淡粉色。前景透明度 0.58、远景约 0.28，另叠加画笔透明度与边缘遮罩，不抢正文。
- 树高、枝形和花位只在初始化随机；树架之后保留。花位在独立的 42–55 秒周期中长留，最后 6 秒淡出，再缓慢开放。花瓣轻微摆动，不闪烁。
