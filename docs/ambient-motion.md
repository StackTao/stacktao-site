# 新生：枝脉、叶芽与持续生长

2026-09-24：原创环境动效「新生」。枝脉从页边缓慢舒展，先出现较早的一根侧枝，随后逐渐分岔，枝尖展开小叶芽。主脉使用灰墨，叶芽点缀低饱和青绿，与暖纸背景和宋体正文配合。

## 视觉与生长顺序

- 桌面四簇、手机两簇；随机选择起点、方向、长短、弯折和分叉位置。主脉跨度约半屏至整屏，集中在页边。
- 多尺度随机偏移生成轨迹，再柔化细碎尖角；主脉、侧枝、细梢采用不同笔重，沿路径逐渐收细。
- 每簇桌面 4–7 条侧枝，手机 2–3 条，越靠近末段越密。桌面部分侧枝长出更细的短梢，等父枝经过后才开始生长。
- 每簇先在主脉的 12%–23% 处生出较早的一根侧枝，其余侧枝逐渐集中于末段。大多数主脉向上生长。
- 主脉用 8–14 秒长出；主脉经过分叉点后停顿 220–650ms，侧枝用 1.5–3 秒长出。细梢在父枝到达后延迟 180ms，再用 1–1.8 秒生长。
- 部分侧枝和细梢在长到末端后，用 1.6 秒展开两片 4–9px 左右的叶芽。叶芽根部固定，只轻轻摆动；低饱和青绿色不扩展为大色块。
- 长成后停留 4–6 秒，再用 8–12 秒平滑淡去。各簇独立重生，随机等待 0.6–1.8 秒后开始新轨迹，持续变化但不整体重播。
- 首次从空白起笔，每簇间隔 2.2 秒，整体用 1.8 秒渐显，不直接显示完成态。

## 阅读与生命周期

- 标题保留同纸色柔边保护；正文沿用透明遮罩。手机降低透明度，不超过 1023px 的文章页只在上下缘显现。
- 刷新、路由或尺寸变化重新构图；主题切换保留轨迹和生长进度。
- 每秒最多绘制 30 帧，DPR 上限 1.5，resize 防抖 180ms。后台暂停，返回后继续原进度。
- 系统减少动态效果下展示完整静态枝脉与叶芽，不运行 rAF。
- `data-ambient-state`：flowing / still / paused；`data-ambient-generation` 记录再生次数。

## 验证

检查初始数秒逐步生长、枝端叶芽随后展开、运行一轮后继续生成、静态模式像素不变，以及浅深主题、演讲页、文章页和手机布局。运行 `node --check public/js/site.js`、`npm run build`，检查控制台无脚本错误。
