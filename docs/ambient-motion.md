# 风迹：随机生成的页边线稿

2026-09-23：将山水背景替换为原创的长线束动画。参考 [antfu.me](https://antfu.me/) 的生成式背景与留白原则，使用独立编写的流场曲线，未采用其树枝分叉实现。

## 构图和运动

- 桌面主线从左下画外向上舒展，较淡的远层从右上入画，弱横流在侧边轻轻交错；移动端只保留上下两组。
- 每组 10–15 条细线，手机为 5 条。线长约半屏至整屏，随视口高度缩放；位置、长度、间距、卷曲方向、浓淡和起笔时间随机。
- 同组曲线沿共享方向场逐笔生长，各自微调走向，首尾通过透明度收尖。约 8–18 秒后完成，停止动画。
- 桌面中部横向透明遮罩保护正文；761–1279px 视口单独扩大透明阅读区域。手机中部纵向透明，并将总透明度降至 0.65。
- 刷新、页面切换或尺寸变化时重新生成；主题切换保留构图。

## 性能与辅助功能

- 原生 Canvas 增量绘制，无外部依赖、图片和模糊滤镜。
- DPR 上限 1.5，resize 防抖 180ms。画完停止 rAF；后台暂停，恢复后继续进度。
- 减少动态效果下直接画出完整随机线迹，不运行动画。
- `data-ambient-state`：growing / settled / still / paused；drawn 与 segments 属性提供生长进度。

## 验证

检查文章与播客页、浅深主题、手机视口。验证生长期间线段增加、完成后静止、刷新得到不同构图、减少动态效果下像素不变。运行 `node --check public/js/site.js` 和 `npm run build`。
