# 四季天光与纸上气候

2026-10-21：替换梅枝动画。以画外淡光和固定纸纹表达季节，不使用具象景物或漂浮粒子，不改变正文、背景底色和阅读布局。

## 视觉与节奏

- 春：暖白与微弱灰绿；夏：青灰与清透蓝灰；秋：浅金与暖灰；冬：冷银与中性灰。
- 从春开始，四分钟一轮，每季一分钟；每季前四十秒停留，后二十秒 smoothstep 混色，轮回处同样连续。
- 两处椭圆光源位于画面外，以几十秒为尺度缓慢游移。浅色透明度上限 0.13 / 0.10，深色上限 0.055 / 0.04，叠加原有页边遮罩。
- 固定 160px 纸纹块内有 720 个稀疏亚像素颗粒，仅初始化时随机；季节影响整体纸感强度，颗粒不移动或逐帧闪烁。
- 初次进入四秒渐显。切换路由、主题或窗口尺寸保留季节进度；后台暂停，回来继续，不追赶时间。
- 中央正文沿用透明遮罩，手机只保留上下缘，窄屏文章进一步降低装饰。

## 性能与无障碍

- 最多 24fps，DPR 上限 1.5，resize 防抖 180ms。
- 减少动态效果时固定为静态春日天光，不运行 rAF。
- data-ambient-state 为 flowing / still / paused；data-ambient-season 为 spring / summer / autumn / winter。
